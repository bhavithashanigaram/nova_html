# HTML & CSS Practice Project

A simple frontend practice project created to improve my understanding of **HTML and CSS**.
This project focuses on building and styling a single-page website using only HTML and CSS.

##  Features

* Single-page website
* Clean and simple UI
* Semantic HTML structure
* CSS-based layout and styling
* Responsive design practice
* Navigation and different webpage sections
* No JavaScript used

## Technologies Used

* HTML5
* CSS3

##  Project Structure

```text
project-folder/
│
├── index.html
├── index.css
└── README.md
```

## 🎯 Purpose

This project was created as a **practice project** to strengthen my fundamentals in:

* HTML structure
* CSS styling
* Flexbox
* CSS Grid
* Spacing and positioning
* Colors and typography
* Responsive layouts
* Creating a clean webpage from scratch

##  How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

You can also use **VS Code with Live Server** to run the project.
